# 3. Учебные материалы

[← Оглавление](../project_details.md)

## Поддерживаемые форматы

- **Текст** — текстовые гайды, туториалы, шпаргалки (cheatsheets)
- **Фото**
- **Видео / аудио** — могут быть интегрированы в те же уроки, что и текстовые материалы

## Урок

Урок — это коллекция материалов (или материал одного типа), которую можно редактировать в процессе.

Уроки объединяются в курсы: см. [Структура курсов](04-course-flows.md).

## Создание с помощью ИИ

См. [ИИ-функции → Создание учебного материала](05-ai-features.md#создание-учебного-материала).

> LLM помогают только с текстовыми материалами — обработка видео сложна и может быть интегрирована в будущем.
