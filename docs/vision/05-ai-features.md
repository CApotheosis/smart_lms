# 5. ИИ-функции

[← Оглавление](../project_details.md)

С помощью ИИ автоматизировать процесс:

1. Проверки выполненных заданий
2. [Создания заданий и материалов](#создание-учебного-материала) на базе знаний заведения (школа, университет, учебный центр и т.д.)
3. Фиксации метаданных и данных — см. [Аналитика и оценка](08-analytics-evaluation.md)
4. [Геймификации](06-gamification.md)
5. [Памяти об ученике](#память-об-ученике)

## Создание учебного материала

Для удобного перехода в систему:

- Создание учебного материала с помощью ИИ — с загрузкой опорных материалов или без них.
- Организация может загрузить собственные материалы и с помощью LLM:
  - обработать их и создать уроки
  - найти ошибки
  - создать задания
  - обновить и проверить на актуальность (можно указать точные источники для сверки или довериться компетенции агента)

Ограничение: только текстовые материалы ([Учебные материалы](03-learning-materials.md)).
Модель оплаты: [Биллинг → Кредиты](09-billing.md#кредитная-модель-для-ии).

## Память об ученике

Создание и обновление памяти об ученике, которая используется для:

- анализа личности
- создания специальных занятий
- уведомления учителя об успешном/неуспешном выполнении задания ([Уведомления](07-notifications.md))
- анализа успеваемости ([Аналитика](08-analytics-evaluation.md))

Стоит подумать над тем, как эта функция может помочь понять и развить ученика. Придумать специальный подход или дополнительные уроки. Можно позволить организации самой определять критерий оценки учеников по своей системе или использовать дефолтный.
