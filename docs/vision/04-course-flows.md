# 4. Структура курсов (флоу для учителя/клиента)

[← Оглавление](../project_details.md)

1. **Отдельные курсы** — создаются и редактируются отдельно, с поэтапным прогрессом (обычные обучающие уроки).
2. **Связанные курсы (learning path, career path)** — доступ к одному открывается после окончания другого, либо свободный доступ к любому курсу из цикла. Для учебных заведений с линейным обучением и взаимозависимыми курсами.
3. **Переплетённые курсы** — контроль нескольких треков одновременно: их очерёдность, прогресс от одного к другому, дополнительные ограничения/задания/аттестация перед продвижением. Для школ, университетов и других учебных заведений с комплексным, кастомизируемым планом обучения.

Курсы состоят из [уроков](03-learning-materials.md#урок).

## Организации

- Эти системы можно создавать сразу при регистрации организации.
- Клиент может иметь любое количество организаций разных или схожих типов.
- Если организация большая, для неё можно сразу выделить отдельный сервер.
